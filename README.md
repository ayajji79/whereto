# ✈️ Travel Course Blog Generator (여행 블로그 올인원 대시보드)

네이버·티스토리 리스트형(BEST N 코스 추천) 여행 전문 블로그 콘텐츠 자동 기획 & 생성 올인원 대시보드입니다.

---

## 🌟 주요 기능

1. **실존 검증 장소 발굴 & 코스 바스켓 (Step 1)**
   - 지역 및 여행 테마(데이트, 힐링 나들이 등) 기반 장소 추천
   - **더미 데이터 배제**: 네이버 지도/플레이스 검증 지표(저장수, 영수증 리뷰수) 연계
   - **상세 실용 정보 제공**: 대표 메뉴 및 가격대, 주차장 구비 여부 및 꿀팁, 다녀온 사람들의 생생한 찐후기
   - 실시간 네이버 지도, 내돈내산 블로그 후기, 카카오맵 교차 검증 링크 지원
   - 나만의 숨은 명소/맛집 직접 코스 등록 기능

2. **SEO & 비주얼 에셋 원클릭 기획 (Step 2)**
   - 타겟 독자 맞춤형 고클릭률 제목(H1) 3종 자동 추천
   - 인스타그램/스레드/네이버 최적화 해시태그 & 핵심 검색어 추출
   - 장소별 하이라이트 에셋 카드 및 썸네일 생성용 AI 이미지 프롬프트 생성

3. **고품질 마스터 프롬프트 & 본문 생성 (Step 3)**
   - 톤앤매너(친근한 인플루언서체, 감성 에세이체, 정보형 백과사전체 등) 선택
   - 검증된 실존 메뉴, 주차 정보, 방문자 찐후기가 포함된 방문 꿀팁 박스 자동 구성
   - Gemini AI 원클릭 글 생성 또는 프롬프트 복사 지원

4. **네이버/티스토리/워드프레스 맞춤 발행 & SNS 패키지 (Step 4)**
   - 네이버 블로그 스마트에디터 서식 맞춤 HTML 원클릭 복사
   - 마크다운(Markdown) 복사 및 텍스트 복사
   - 인스타그램 카드뉴스 캡션, 릴스/쇼츠 대본, 스레드용 요약 패키지 자동 생성
   - 구글 스프레드시트(GAS) 연동 히스토리 자동 보관

---

## 🚀 빠른 시작 가이드 (Getting Started)

### 1. 패키지 설치
```bash
npm install
```

### 2. 로컬 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속합니다.

### 3. 프로덕션 빌드
```bash
npm run build
```

---

## 🛠️ 기술 스택
- **Frontend**: HTML5, Tailwind CSS, FontAwesome, JavaScript (Modular ES Architecture)
- **AI Integration**: Google Gemini API (@google/genai)
- **Build Tool**: Vite, Node.js
- **Cloud/Database**: Google Apps Script (GAS) 연동 지원
