Google Apps Script (GAS) 연동 코드 복사

구글 스프레드시트의 [확장 프로그램] ➔ [Apps Script]에 위 코드를 붙여넣고, [배포] 시 액세스 권한을 '모든 사용자(Anyone)'로 설정한 뒤 배포된 URL을 위 입력란에 넣으면 됩니다.

Gemini API 무료 키 발급 상세 안내

1. Google AI Studio에 접속하여 구글 계정으로 로그인합니다.

2. 화면 중앙의 [Create API key] 버튼을 누릅니다.

3. 생성된 키(AIzaSy로 시작)를 복사하여 위 API Key 입력칸에 붙여넣습니다.

4. [Ping 테스트]를 눌러 정상이면 [설정 저장하기]를 클릭합니다. 무료 티어로 매일 수천 건의 고품질 분석을 이용할 수 있습니다.

구글 스프레드시트 3분 연동 상세 가이드

1. Google Sheets에서 새 스프레드시트를 생성합니다.

2. 상단 메뉴 [확장 프로그램] ➔ [Apps Script]를 클릭합니다.

3. 위 [코드 전체 복사] 버튼을 눌러 코드를 복사한 뒤 Apps Script 편집창에 모두 붙여넣습니다.

4. 우측 상단 [배포] ➔ [새 배포] 클릭 ➔ 유형: [웹 앱] 선택.

5. 액세스 권한: '모든 사용자(Anyone)'로 설정 후 배포합니다.

6. 생성된 웹 앱 URL을 위 입력란에 붙여넣고 [설정 저장하기]를 누르면 완료됩니다.
